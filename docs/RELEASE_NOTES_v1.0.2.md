# Release Notes - CleanYourWechatTool v1.0.2

**发布日期**: 2026-09-08
**类型**: 交互体验大版本 (macOS 原生习惯全面对齐)

---

## 🍃 新应用图标

应用图标重绘为树叶主题（微信绿渐变 + 白叶 + 叶脉 + 对勾）——贴合"轻量、瘦身"的产品定位。

## 🖱 macOS 原生操作习惯 (文件清单)

- **双击文件行**：用系统默认程序直接打开该视频/文档；
- **按空格键**：唤起 macOS 标志性的 Quick Look 快速预览（无需跳出应用去访达）；
- **右键菜单**：在访达中显示 / 包含 / 排除 / 加入白名单保护；
- **点击表头排序**：按大小 / 修改日期 / 路径排序，再次点击反转方向（带 ▾▴ 指示）。

## ☑ 清单即决策：勾选排除，执行只删勾选项

预览清单中的每个文件都可以单独排除（点击"含"列切换 ☑/☐，或 Shift/Ctrl 多选后右键批量排除）。
执行清理时**只处理清单中未排除的文件**，不再把过滤参数重新全量执行一遍——
预览阶段看到什么、排除什么，执行就动什么。

## 🏆 累计成就仪表

底部状态栏常驻"已累计为这台 Mac 释放 XX 空间（清理 N 次 / 去重 M 次）"，
每次清理或去重后实时刷新。

## ⏳ 动态进度与可取消

大库扫描 / 指纹计算 / 全量校验各阶段实时上报进度计数（"已检查 14,320/15,000 个文件…"），
并提供取消按钮——数万文件规模下不再有"假死"焦虑。

## 🔁 去重界面升级为交互表格

重复文件清单从纯文本升级为两级表格（组 + 文件行，绿色=保留底稿、红色=重复副本）：
- 右键**"将此文件设为保留底稿"**，自由切换保留哪一份副本；
- 双击在访达中定位；
- 执行遵循切换后的保留状态。

## 📂 多账号与自定义目录

- 顶部账号下拉框列出全部发现的微信账号及占用大小，切换即重扫；
- 支持"重新检测"与"自定义微信目录"，自动探测受挫时可手动指定。

## 🛡 防御死线

引擎与界面双侧物理拉黑数据库及程序组件后缀（`.db/.sqlite/.ldb/.sst/.dll/.dylib/.pak` 等）
与运行时目录（`bin/runtime/frameworks/resources`），任何清理规则都不可触碰——
即使未来目录结构变化或使用自定义路径，聊天数据库与微信本体也不会受损。

## 下载

| 机型 | 文件 |
|---|---|
| Apple Silicon (M1/M2/M3/M4) | `CleanYourWechatTool-arm64.dmg` |
| Intel | `CleanYourWechatTool-x86_64.dmg` |

首次打开提示"已损坏/无法验证开发者"（应用未经公证）：右键应用图标 → 打开；
或终端执行 `xattr -cr /Applications/CleanYourWechatTool.app`。

提示"未找到微信数据"：系统设置 → 隐私与安全性 → 完全磁盘访问权限，
将本应用加入列表后重启（应用内也会一键引导跳转该设置面板）。

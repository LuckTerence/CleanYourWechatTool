## 使用示例
```bash
# 添加白名单联系人
python3 clean_wechat.py tag \
  --add "老婆" \
  --wxid "wxid_xxx123456" \
  --tags family,partner \
  --protect absolute

# 列出所有受保护的联系人
python3 clean_wechat.py tag --list

# 从白名单移除
python3 clean_wechat.py tag --remove wxid_xxx123456
```

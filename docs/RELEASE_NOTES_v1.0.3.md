# Release Notes - CleanYourWechatTool v1.0.3

**发布日期**: 2026-09-09
**类型**: 全新界面 + 交互重构（渐进式披露）

---

## 🎨 全新界面：微信智能空间管家

界面整体重构为 CustomTkinter 原生质感（深浅色自适应），信息层级收敛为：
**一屏核心看板 + 三张智能建议卡片 + 一个主操作按钮**。

- 顶部看板：微信当前占用 / 预计可安全释放 / 一键安全瘦身
- 三张智能建议卡片：基础系统垃圾（零风险）、多群转发重复文件（无损合并）、历史大文件（空间大户）
- 每张卡片独立开关，释放总量与按钮状态实时联动
- 底部常驻累计成就与操作状态

## 🍃 树叶版应用图标

新图标：微信绿渐变 + 白叶 + 叶脉 + 对勾，贴合"轻量、瘦身"的定位。

## 🧩 渐进式披露：默认极简，需要时可选

不做参数铺陈，也不砍能力——

- **默认**：推荐值已选好（90 天前 / 大于 10MB / 视频与接收文件），普通用户零配置、零术语
- **可选**：每张卡片提供「调整筛选条件」折叠区
  - 历史大文件：清理时间 / 最小大小 / 文件类型，改完自动重算
  - 重复文件：重复判定大小阈值
- **核对**：历史大文件支持打开明细抽屉，逐条勾选后再执行

## 🛡 稳定性与正确性修复

- 取消链路修复：任务取消不再被当作"完成"渲染（正确显示"已取消"）；去重阶段支持取消与进度
- 任务重叠防护：后台任务进行中拒绝新任务，避免状态互相覆盖
- Python 3.8 兼容修复（哈希参数在 3.9+ 才支持，导致 3.8 环境失败）
- 统计准确性：累计释放/保护数据统计修正
- 防御死线：数据库与程序组件后缀、运行时目录物理拉黑，任何规则都不可触碰

## 下载

| 机型 | 文件 |
|---|---|
| Apple Silicon (M1/M2/M3/M4) | `CleanYourWechatTool-arm64.dmg` |
| Intel | `CleanYourWechatTool-x86_64.dmg` |

首次打开提示"已损坏 / 无法验证开发者"（应用未经 Apple 公证）：
右键应用图标 → 打开；或终端执行 `xattr -cr /Applications/CleanYourWechatTool.app`。

提示"未找到微信数据"：系统设置 → 隐私与安全性 → 完全磁盘访问权限，
将本应用加入列表后重启（应用内也会一键引导跳转该设置面板）。

# Release Notes - CleanYourWechatTool v1.0.4

**发布日期**: 2026-09-09
**类型**: 智能两步筛选 + 零 Emoji 纯净交互 + 办公重要文档锁定保护

---

## 精准两步筛选机制 (先选人，后选文件)

全面重构历史大文件的筛选模式，打破微信自带清理“整群整人一刀切”的暴力清除逻辑：

1. **第一步 · 核心人脉防删白名单（先选人/群）**：
   - 筛选面板顶部常驻白名单守护条，一键直达「管理保护名单」；
   - 自动避开白名单联系人/重要群聊，以及含有「合同/发票/方案」关键词的核心文件。
2. **第二步 · 细粒度文件类型选择（后选文件）**：
   - 聊天大视频 (.mp4 / .mov 等) —— 默认不勾选；
   - 临时压缩包/安装包 (.dmg / .zip / .pkg 等) —— 默认不勾选；
   - 办公重要文档 (.pdf / .docx / .xlsx 等) —— 默认锁定保护，防手滑误删。
3. **100% 自主掌控（默认零勾选）**：
   - 历史大文件初始处于 100% 绝对保护锁定状态，绝不自作主张勾选任何项目；
   - 只有用户主动确认并打勾的项目才会被纳入预估清理范围。

## 零 Emoji 纯净专业界面

- 按照企业级与严谨生产力工具标准，移除所有 Emoji 表情符号，提供干净、专业、现代的 UI 界面体验；
- 明细抽屉增加清晰的文本类别标识（视频、压缩包、文档、其他）。

## 质量与测试

- 全套 83 项单元与集成测试全绿通过；
- CI 持续集成覆盖 Python 3.8–3.12 跨平台测试及安全审计。
